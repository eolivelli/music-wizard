# This directory contains a list of real mp3 files

gmajorblues.mp3

This is a simple Blues is G Major.
It's 12 bars repeated many times.
The sequence is: 
G7 G7 G7 G7
C7 C7 G7 G7
D7 C7 G7 D7

blues-a-90bpm.mp3   (LOCAL ONLY — not committed; standard YouTube license)

A blues backing track in A at 90 BPM, 5:04. Not redistributable, so the
file itself is gitignored; fetch it yourself for local testing:
  yt-dlp -x --audio-format mp3 -o samples/blues-a-90bpm.mp3 \
    https://www.youtube.com/watch?v=Z3euxRLOQec
12 bars repeated, slow change, E7 turnaround:
A7 A7 A7 A7
D7 D7 A7 A7
E7 D7 A7 E7

blues-shuffle-a-106bpm.mp3   (LOCAL ONLY — not committed; standard YouTube license)

Blues shuffle in A at 106 BPM, 5:43. Same source channel and same licensing
posture as blues-a-90bpm.mp3; fetch locally:
  yt-dlp -x --audio-format mp3 -o samples/blues-shuffle-a-106bpm.mp3 \
    https://www.youtube.com/watch?v=lFV6mqP7rfY
Same 12-bar sequence as blues-a-90bpm.mp3, shuffled feel:
A7 A7 A7 A7
D7 D7 A7 A7
E7 D7 A7 E7

blues-e-90bpm.mp3   (LOCAL ONLY — not committed; standard YouTube license)

Blues backing track in E at 90 BPM, 5:02. Same source channel and licensing
posture as the other backing tracks; fetch locally:
  yt-dlp -x --audio-format mp3 -o samples/blues-e-90bpm.mp3 \
    https://www.youtube.com/watch?v=36X3wecT2z8
Same 12-bar shape as the A-blues tracks, in E:
E7 E7 E7 E7
A7 A7 E7 E7
B7 A7 E7 B7

bossa-cm.mp3   (LOCAL ONLY — not committed; standard YouTube license)

Bossa nova backing track in C minor. Fetch locally:
  yt-dlp -x --audio-format mp3 -o samples/bossa-cm.mp3 \
    https://www.youtube.com/watch?v=7H7Xg6U7P5g
16 bars; "0" is half-diminished, "DELTA" a major seventh; the last bar
holds two chords, half a bar each:
Cm7  Cm7  Fm6  Fm6
D0   G7   Cm6  Cm6
Ebm7 Ab7  DbDELTA DbDELTA
D0   G7   Cm6  D0-G7
